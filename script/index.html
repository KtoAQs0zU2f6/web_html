    JavaScriptを実行する <script>

    JavaScriptのプログラムをページに書き込んで実行する。

    HTML要素 ／ スクリプト・描画

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <script> は、JavaScriptを実行するタグです。この図鑑では、JavaScriptの書き方は解説しません。

    実行結果

    コード

    HTML
    <p id="msg">(ここに結果が出ます)</p>
<script>
  document.getElementById("msg").textContent = "JavaScriptが実行されました";
</script>

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • JavaScriptの中身はこの図鑑の対象外です。
    • 外部のファイルを読み込むときは、src 属性にファイルの場所を書きます。

    関連コード

    • <canvas> 描画領域
    • <noscript> JavaScriptが使えないとき
