    独立した記事 <article>

    ニュースやブログ記事など、それだけで意味が通じるまとまり。

    HTML要素 ／ セクション(ページの区分け)

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <article> は、その部分だけを切り出しても意味が通じる、独立したまとまりを表します。ブログ記事、ニュース、コメントなどに使います。

    記事の中に、さらにコメントなどの <article> を入れることもできます。

    実行結果

    コード

    HTML
    <article>
  <h2>お知らせ</h2>
  <p>年末年始の診療についてのご案内です。</p>
</article>
    CSS
    article { border: 1px solid #ccd; padding: 12px 16px; border-radius: 8px; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 見出しをつけるのが基本です。
    • 単なる区切りには <div> や <section> を使います。

    関連コード

    • <section> 内容の区切り
    • <aside> 補足・脇の情報
    • <header> ヘッダー(冒頭)
