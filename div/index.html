    意味を持たない箱 <div>

    特別な意味はなく、まとまりを作ってCSSで整えるための箱。

    HTML要素 ／ テキストのブロック

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <div> は、意味を持たない汎用の箱です。まとめてCSSを当てたり、レイアウトを組んだりするときに使います。

    意味のあるタグ(<section>、<article>、<nav> など)があるときは、そちらを優先します。

    実行結果

    コード

    HTML
    <div class="box">
  <p>div の中の文章です。</p>
</div>
    CSS
    .box { background: #eef3ff; border: 2px solid #5b7bd5; padding: 16px; border-radius: 8px; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 初期設定では、横幅いっぱいに広がる箱になります。
    • 意味のあるタグが使える場面で、<div> を多用しない方が構造が伝わります。

    • <section> 内容の区切り
