    説明リスト <dl>

    用語とその説明を対にして並べるリスト。

    HTML要素 ／ テキストのブロック

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <dl> は、用語(<dt>)とその説明(<dd>)を対にして並べるときに使うリストです。用語集や、項目と値の組を並べる場面に向いています。

    実行結果

    コード

    HTML
    <dl>
  <dt>診療科</dt>
  <dd>泌尿器科・腎臓内科</dd>
  <dt>診療時間</dt>
  <dd>平日 9:00〜18:00</dd>
</dl>
    CSS
    dt { font-weight: bold; }
dd { margin: 0 0 8px 1em; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 用語と説明の対応を保ったまま、<div> でグループ化することもできます。

    関連コード
