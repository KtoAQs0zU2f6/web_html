    引用(ブロック) <blockquote>

    ほかの文章から引用した、まとまった文章を示す。

    HTML要素 ／ テキストのブロック

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <blockquote> は、ほかの人や資料から引用した文章のまとまりに使います。出典のURLは cite 属性に書けます。

    出典の名前を画面に見せたいときは、<figure> と <figcaption>、<cite> を組み合わせます。

    実行結果

    コード

    HTML
    <blockquote cite="https://example.com/source">
  <p>引用したい文章がここに入ります。</p>
</blockquote>
    CSS
    blockquote { margin: 0; padding: 8px 16px; border-left: 4px solid #99a; background: #f6f7fb; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 初期設定では左右に余白ができます。
    • 文中の短い引用は <q> を使います。

    関連コード

    • <q> 短い引用
    • <cite> 作品の題名
    • <figure> 図・写真のまとまり
