    意味を持たない文字の囲み <span>

    文中の一部に、意味を足さずにCSSを当てるための囲み。

    HTML要素 ／ 文中のテキスト

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <span> は、意味を持たない汎用のインライン要素です。文章の一部だけにCSSで色やサイズを当てるときに使います。

    ブロックのまとまりには <div> を使います。

    実行結果

    コード

    HTML
    <p>この中の <span class="hl">一部だけ</span> に色がつきます。</p>
    CSS
    .hl { color: #c0392b; font-weight: bold; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • <span> は、改行を入れずに文の流れの中に置かれます。
