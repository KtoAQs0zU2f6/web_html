    スクロールしても残るヘッダー position: sticky

    スクロールしても、画面の上に固定されたままのヘッダー。

    CSSレイアウト ／ CSSレイアウト

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    position: sticky と top: 0 を指定すると、その要素は、スクロールしても画面の上端にくっついて残ります。固定ヘッダーによく使います。

    実行結果

    コード

    HTML
    <div class="sh">固定ヘッダー</div>
<p>スクロールして試してください。</p>
<p>文章1</p><p>文章2</p><p>文章3</p><p>文章4</p><p>文章5</p>
<p>文章6</p><p>文章7</p><p>文章8</p><p>文章9</p><p>文章10</p>
<p>文章11</p><p>文章12</p><p>文章13</p><p>文章14</p><p>文章15</p>
    CSS
    .sh { position: sticky; top: 0; background: #1f4fb0; color: #fff; padding: 10px 16px; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 親要素に overflow: hidden などがあると、うまく効かないことがあります。
