    アコーディオン details + summary

    見出しをクリックして、答えを開閉するQ&Aの部品。

    部品 ／ よく使う部品

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    アコーディオンは、見出しをクリックすると内容が開閉する部品で、よくある質問(FAQ)などに使います。<details> と <summary> を使えば、JavaScriptなしで作れます。

    実行結果

    コード

    HTML
    <details class="qa">
  <summary>予約は必要ですか?</summary>
  <p>予約なしでも受診できます。</p>
</details>
<details class="qa">
  <summary>支払い方法は?</summary>
  <p>現金のほか、一部のカードが使えます。</p>
</details>
    CSS
    .qa { border: 1px solid #ccd; border-radius: 8px; padding: 8px 14px; margin-bottom: 8px; }
.qa summary { font-weight: bold; cursor: pointer; }
.qa p { margin: 8px 0 0; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 1つ開くと他が閉じる動きにするには、JavaScriptまたは追加の属性が必要です。
