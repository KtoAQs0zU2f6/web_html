@@ a
tag: <a>
title: リンク
group: inline
summary: 別のページや場所へ移動するリンクを作る。
keywords: えー りんく アンカー href url 飛ぶ ハイパーリンク
related: nav, img, button
>> explain
`<a>` は、クリックすると別のページやページ内の場所に移動するリンクを作ります。行き先は `href` 属性で指定します。

`target="_blank"` を付けると新しいタブで開きます。このとき `rel="noopener"` も付けておくと安全です。
>> html
<p><a href="https://example.com/">外部サイトへのリンク</a></p>
<p><a href="#bottom">ページ内のリンク</a></p>
>> css
a { color: #1f4fb0; }
a:hover { text-decoration: none; }
>> notes
- リンクの文字は「こちら」ではなく、行き先がわかる言葉にします。
- 画面内の枠では、リンクを押すと移動先が枠の中に表示されることがあります。

@@ abbr
tag: <abbr>
title: 略語
group: inline
summary: 略語を示し、`title` で正式名称を添える。
keywords: あぶりびえーしょん 略語 略称 省略
related: dfn
>> explain
`<abbr>` は略語や略称を示します。`title` 属性に正式な名前を書くと、マウスを乗せたときに表示されます。
>> html
<p><abbr title="HyperText Markup Language">HTML</abbr> はウェブページを作る言語です。</p>
>> css
abbr[title] { text-decoration: underline dotted; }
>> notes
- スマホではマウスを乗せられないため、`title` の内容が見られない場合があります。

@@ b
tag: <b>
title: 目立たせる文字
group: inline
summary: 意味の強調ではなく、目立たせたい語を太字にする。
keywords: びー 太字 ボールド 強調 キーワード
related: strong, em, mark
>> explain
`<b>` は、文章の中で目立たせたい語(製品名やキーワードなど)に使います。太字で表示されますが、重要度の意味はもちません。

重要な内容には `<strong>` を使います。
>> html
<p>この薬は <b>ビタミン剤</b> として使われます。</p>
>> notes
- 太字にするだけが目的なら、CSSの `font-weight` も使えます。

@@ bdi
tag: <bdi>
title: 文字方向の分離
group: inline
summary: 書く向きが不明な文字を、周りと独立して扱う。
keywords: びーでぃーあい 双方向 文字方向 右から左 アラビア語
related: bdo
>> explain
`<bdi>` は、ユーザー名のように、文字の書く向き(左から右か、右から左か)が前もってわからない文字を囲みます。周りの文字の向きに影響されずに表示されます。

日本語だけのページで使う機会は多くありません。
>> html
<ul>
  <li>ユーザー: <bdi>田中</bdi> — 12点</li>
  <li>ユーザー: <bdi>إيان</bdi> — 5点</li>
</ul>
>> notes
- 右から左へ書く言語(アラビア語など)を扱うときに役立ちます。

@@ bdo
tag: <bdo>
title: 文字方向の上書き
group: inline
summary: 文字の書く向きを、指定した向きに強制する。
keywords: びーでぃーおー 文字方向 逆向き dir rtl
related: bdi
>> explain
`<bdo>` は、文字の書く向きを `dir` 属性で強制的に決めます。`dir="rtl"` なら右から左、`dir="ltr"` なら左から右になります。
>> html
<p><bdo dir="rtl">abc 123</bdo></p>
>> notes
- `dir` 属性は必ず指定します。

@@ br
tag: <br>
title: 改行
group: inline
summary: 文章の途中で改行する。終了タグはない。
keywords: ぶーあーる 改行 かいぎょう 折り返し
related: p, wbr
>> explain
`<br>` は、その場所で改行するタグです。住所や詩のように、改行そのものに意味がある文章に使います。

段落を分けたいときは、改行を重ねずに `<p>` を使います。
>> html
<p>埼玉県鴻巣市<br>サンプル町1-2-3</p>
>> notes
- 行間をあけるために `<br>` を重ねるのは避け、CSSの余白を使います。

@@ code
tag: <code>
title: コードの文字列
group: inline
summary: プログラムのコードやタグ名など、コードを表す文字。
keywords: こーど ソースコード 等幅 プログラム
related: pre, kbd, samp
>> explain
`<code>` は、文中に出てくるコードの断片を表します。等幅フォントで表示されます。

複数行のコードは、`<pre>` と組み合わせます。
>> html
<p>段落は <code>&lt;p&gt;</code> タグで書きます。</p>
>> css
code { background: #f1f3f8; padding: .1em .35em; border-radius: 4px; }
>> notes
- `<` と `>` を表示するには、`&lt;` と `&gt;` と書きます。

@@ em

@@ q
