    見た目を整えたボタン .btn

    色・角丸・押したときの変化をつけた、見栄えのよいボタン。

    部品 ／ よく使う部品

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <button> や <a> にCSSを当てて、見栄えのよいボタンにする例です。背景色、角の丸み、マウスを乗せたときの色の変化を指定しています。

    リンクをボタンの見た目にするときは、<a> に同じCSSを当てます。

    実行結果

    コード

    HTML
    <button class="btn">保存する</button>
<button class="btn btn-sub">キャンセル</button>
    CSS
    .btn { padding: 10px 22px; border: 2px solid #1f4fb0; border-radius: 8px; background: #1f4fb0; color: #fff; font-size: 16px; cursor: pointer; transition: background .15s; }
.btn:hover { background: #163a85; }
.btn-sub { background: #fff; color: #1f4fb0; }
.btn-sub:hover { background: #eef3ff; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • ボタンは、マウスを乗せたときや、キーボードで選んだときの見た目も用意すると親切です。
