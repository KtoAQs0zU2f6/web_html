    番号つきリスト <ol>

    順番に意味がある項目を、番号をつけて並べる。

    HTML要素 ／ テキストのブロック

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <ol> は、順番に意味がある項目を並べるリストです。手順やランキングなどに使い、項目には自動で番号がつきます。

    start 属性で開始番号を、reversed で逆順を指定できます。

    実行結果

    コード

    HTML
    <ol>
  <li>受付をする</li>
  <li>問診票を書く</li>
  <li>診察を受ける</li>
</ol>

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 順番に意味がないものは <ul> を使います。
