    パンくずリスト .crumbs

    「ホーム › 診療案内 › 泌尿器科」のような、現在地の道筋。

    部品 ／ よく使う部品

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    パンくずリストは、いま見ているページが、サイトのどこにあるかを示す道筋です。<nav> の中に <ol> を使い、CSSで区切りの記号をつけます。

    実行結果

    コード

    HTML
    <nav aria-label="パンくずリスト">
  <ol class="crumbs">
    <li><a href="#">ホーム</a></li>
    <li><a href="#">診療案内</a></li>
    <li>泌尿器科</li>
  </ol>
</nav>
    CSS
    .crumbs { display: flex; flex-wrap: wrap; gap: 6px; list-style: none; padding: 0; }
.crumbs li + li::before { content: "›"; margin-right: 6px; color: #889; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 区切りの記号は、CSSの ::before で付けると、HTMLがすっきりします。
