    図・写真のまとまり <figure>

    図、写真、コードなどを、説明文と組にして囲む。

    HTML要素 ／ テキストのブロック

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <figure> は、本文から独立して意味を持つ図、写真、コード、表などを囲むタグです。<figcaption> で説明をつけられます。

    本文の流れの外に移しても、意味が通じるものに使います。

    実行結果

    コード

    HTML
    <figure>
  <img src="sample.svg" alt="山と太陽のイラスト" width="240">
  <figcaption>図1 サンプル画像</figcaption>
</figure>
    CSS
    figure { margin: 0; display: inline-block; text-align: center; }
figcaption { font-size: 14px; color: #556; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 初期設定では左右に余白がつきます。
