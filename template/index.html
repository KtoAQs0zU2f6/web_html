    表示しない雛形 <template>

    すぐには表示せず、あとで使うために置いておくHTMLの雛形。

    HTML要素 ／ Web Components

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <template> の中に書いたHTMLは、ページには表示されません。あとからJavaScriptで複製して使うための雛形として使います。

    実行結果

    中身は表示されません。JavaScriptで取り出して使います。

    コード

    HTML
    <template id="row">
  <tr><td>名前</td><td>値</td></tr>
</template>

    注意点

    • 中身は画面に表示されません。使い方にはJavaScriptが必要です(この図鑑では解説しません)。
