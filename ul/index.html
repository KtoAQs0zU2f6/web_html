    番号なしリスト <ul>

    順番に意味がない項目を、点つきで並べる。

    HTML要素 ／ テキストのブロック

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <ul> は、順番に意味がない項目を並べる、箇条書きのリストです。初期設定では項目の前に黒い点が表示されます。

    メニューの横並びなど、点が不要なときは、CSSで list-style: none を指定します。

    実行結果

    コード

    HTML
    <ul>
  <li>りんご</li>
  <li>みかん</li>
  <li>ぶどう</li>
</ul>
    CSS
    ul { padding-left: 1.5em; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • <ul> の直接の子は <li> にします。
