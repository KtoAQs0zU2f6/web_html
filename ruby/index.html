    ルビ(ふりがな) <ruby>

    漢字などの上に、読みを小さく表示する。

    HTML要素 ／ 文中のテキスト

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <ruby> は、漢字の読み(ふりがな)をつけるためのタグです。ふりがなの文字は <rt> で、ルビ非対応の環境向けの括弧は <rp> で書きます。

    実行結果

    コード

    HTML
    <p><ruby>泌尿器科<rp>(</rp><rt>ひにょうきか</rt><rp>)</rp></ruby>の診察です。</p>
    CSS
    rt { font-size: 60%; }

    試してみる

    左の欄を書き換えると、右の結果がすぐ変わります。

    注意点

    • 長い言葉の途中でふりがなを切り替えたいときは、<ruby> の中に複数の組を書けます。

    関連コード

    • <rt> ルビの読み
    • <rp> ルビ非対応用の括弧
