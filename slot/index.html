    Web Componentsの差し込み口 <slot>

    Web Componentsで、利用側が内容を差し込む場所を作る。

    HTML要素 ／ Web Components

    この解説は確認前です。内容に誤りがある可能性があります。

    何ができるか

    <slot> は、Web Components(自作のHTMLタグ)の中で、利用する側が書いた内容を差し込む場所です。JavaScriptで部品を定義して使うため、通常のページを作るだけなら使いません。

    実行結果

    Web Components(JavaScriptで定義する部品)の中で使うため、この図鑑では結果を表示しません。

    コード

    HTML
    <template id="card">
  <div class="card">
    <slot name="title">タイトルなし</slot>
  </div>
</template>

    注意点

    • JavaScriptでの部品の定義は、この図鑑では解説しません。
